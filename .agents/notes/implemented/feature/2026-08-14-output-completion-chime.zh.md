# Agent Note: Web GUI 的离开门控完成提示音

Status: implemented

[English](2026-08-14-output-completion-chime.md) | 中文

## Problem

长时会话迫使操作者一直盯着 GUI：页面不在焦点时没有任何完成信号，操作者要么盯着进度条，要么只能碰巧发现会话已经跑完。侧边栏完成点（[session-completed-done-dot](2026-08-06-session-completed-done-dot.md)）是页面内、按选中门控的，够不到已经离开页面的操作者。

## Decision

新客户端插件（`@deepseek-ai/dsh-client-ui-output-alert`）播放一声短促的合成提示音——WebAudio 两声柔和正弦音，不打包音频资源，音量固定——触发条件恰为：**根会话**（子代理派生会话从不触发）转为完全空闲，**且**此刻用户离开页面（完成瞬间 `document.hasFocus() === false`，无防抖）。每次完成只响一声、从不重复：错过即错过是刻意设计（操作者大概率不在工位，重复响会打扰他人）。页面聚焦时不新增任何提醒——操作者自己会看，现有完成点已覆盖。

"完全空闲"是整个谓词，而非仅运行位：不运行、无排队回合、无待响应的审批/提问交互。对象层发布空闲边沿（`SessionManager.onRootSessionIdle` → `ISessions.onRootSessionIdle`），UI 从不自行推导。管理器在 `completedNotifications` 相同的变更节奏内急切地核对谓词——每次列表变更、列表拉取、待交互帧与队列帧之后——并在变更路径内同步通知监听器，因此隐藏标签页也能及时收到（微任务投递；`Notifier` 用于流式刷新的 rAF 在后台标签页会被暂停）。空闲基线按连接代际重新播种，断连时的待交互清空永远不会被误判为完成（断连窗口内错过的完成属可接受的损失）。`origin: 'subagent'` 的行被排除；未实例化的会话视为队列为空（保守，绝不延迟边沿）。

提示音受一项持久设置门控：`ui-output-alert.enabled`（默认开）——插件宿主半注册的 Host 设置命名空间，浏览器半经 `ctx.settingsScope` 绑定、镜像进行存储，并在设置面板常规分区渲染为复选框行。apiproxy 的对外服务命名空间允许名单（`WEB_SETTINGS_NAMESPACES`）接纳了该命名空间，开关写入因此能持久化到 Host 设置文档。AudioContext 惰性创建，并在页面首次手势时武装（自动播放策略）；武装后即可在后台标签页播放。[Web 术语表](../../../../CONTEXT.md) 记录了领域术语（会话空闲 / 离开页面 / 输出结束提醒）。

## Alternatives considered

**系统级浏览器通知**——不采用，改用声音。操作者要的是在工位时把自己叫回来的信号；通知中心条目对不在机器旁的操作者毫无帮助，还需要权限机制。

**重复响铃直到用户回来**——不采用。操作者选择了单次：没听到就意味着人不在工位，重复响会打扰周围人。

**离开门控加防抖窗口**——不采用。防抖窗口会把"错过"从概率事件变成确定性事件（恰在切走之后完成的场景），而误触发（半在场时多响一声）是自愈的。

**所有会话都响，含子代理**——不采用。子代理逐个完成是进度不是完成；工作流还在跑就会连响。只有根会话才对应"你的会话完成了"。

**区分 `turn/end` 原因**——不采用。快照目前不带原因，而且除手动中止外，任何进入空闲的原因都值得回来处理；手动中止必须先回到页面，离开门控已经排除该场景。

**仅凭 running→idle 位报警**——不采用。排队模式下空闲窗口后可能还排着回合；完整谓词（运行位 + 队列 + 待交互）才是唯一诚实的"完成"。

## Consequences

操作者可以离开 GUI，根会话完成时一声轻提示即可把人叫回来。代价：运行时多发布一种边沿（只发布事实；离开门控与开关留在插件侧），设置文档新增一个命名空间，漏报仍然可能发生（断连窗口、未武装的音频上下文）。同一 GUI 的两个标签页会对同一次完成各响一声；跨标签去重留待出现标签管理器后再做。

## Verification

运行时套件经状态帧、待交互帧、队列帧、刷新拉取、子代理行、退订与断连重播种驱动该边沿。插件套件覆盖离开门控（聚焦与失焦）、开关标志、手势武装、挂起/不可用跳过、webkit 回退，以及行的存储镜像与写入路由。组装态设置对话框快照（[settings-chrome](../../../../apps/web/tests/snapshots/settings-chrome/dialog.expected.md)）固定了新行在常规分区中的呈现。
