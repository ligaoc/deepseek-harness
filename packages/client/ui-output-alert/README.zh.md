# @deepseek-ai/dsh-client-ui-output-alert

[English](README.md) | 中文

会话输出结束提醒：当**根会话**（子代理派生会话从不触发）转为空闲——不运行、无排队回合、无待响应的审批/提问——且用户此刻不在注视页面（完成瞬间 `document.hasFocus() === false`）时，浏览器播放一声短促的合成提示音（WebAudio 两声柔和正弦音，不打包音频资源）。页面可见时不新增任何提醒：用户自己会看，现有侧边栏完成标记已覆盖。每次完成只响一声、从不重复——错过即错过（用户大概率不在工位，重复响会打扰他人）。

触发边沿来自 sessions 服务的 `onRootSessionIdle` 订阅（`SessionRuntime` → `SessionManager`），在对象层变更路径内同步触发，因此隐藏标签页也能及时收到（微任务投递，绝不经过后台标签页会被暂停的 rAF 刷新）。宿主半注册 `ui-output-alert` 设置命名空间；浏览器半通过 `ctx.settingsScope` 绑定它，把 `enabled` 标志镜像进行存储，并在设置面板常规分区渲染一个复选框行（默认开；这是该功能唯一的配置面）。

提示音的 AudioContext 惰性创建，并在页面首次手势时武装（自动播放策略）；武装后即可在后台标签页播放。在有任何手势前就完成的场景（实际几乎不可能——发消息本身就是手势）会跳过。

## Model Experience

无，提示音只是对客户端已可见会话状态的浏览器呈现：不向模型请求发送任何内容，也不新增会话事件（空闲边沿由现有状态、队列与交互帧派生）。

#### KV Cache effect

无；本包既不组装也不发送任何 provider 请求。

## Known Limitations and Deferred Work

- **每个浏览器标签页各响一声**——同一 GUI 的两个标签页会对同一次完成各自播放提示音；跨标签去重留待出现标签管理器后再做。
- **连接闪断期间的完成可能漏报**——空闲基线在重连时重新播种，断线窗口内错过的完成不会响（侧边栏圆点仍会显示）。与"错过即错过"契约一致。
- **音量和音色固定**——提示音刻意不做可调项；开关是唯一配置。
